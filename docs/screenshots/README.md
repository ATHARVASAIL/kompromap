# Screenshots

Drop PNGs here with these exact names and the README's screenshot table
will render them:

| File | What to capture |
|---|---|
| `graph.png` | The graph with a path-finding result highlighted |
| `dashboard.png` | Dashboard showing the threat gauge and severity chart |
| `findings.png` | Findings table with a few severity bands visible |
| `path.png` | Path Analysis with a chain expanded, showing the score breakdown |

Load the sample dataset first (`sample-data/`) so there's something worth
looking at. Full-window captures at a normal browser size read better than
cropped ones.
